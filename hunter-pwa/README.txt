HUNTER SYSTEM - PWA

Структура:
  index.html, manifest.json, sw.js, icons/ (180, 192, 512 px)

Запуск:
1. Загрузите ВСЁ содержимое папки на GitHub Pages или Netlify Drop (нужен HTTPS).
2. Откройте ссылку на iPhone в Safari -> Поделиться -> На экран Домой.
3. Один раз откройте приложение с интернетом, потом проверьте в авиарежиме.

Обновление: измените файлы, поменяйте V = 'hunter-v1' на 'hunter-v2' в sw.js,
загрузите заново, затем закройте и откройте приложение дважды.
